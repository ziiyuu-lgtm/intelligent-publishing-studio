# 多刊投稿审稿后台：本地测试说明

这是独立于原有静态演示页面的开发版后台，仅供虚构数据测试。它尚未连接 SCIENTARA 网站，不能用于真实稿件，也不能开放到公网。

目前可测试：机构与多刊、期刊角色、作者创建并提交稿件、编辑邀请本刊审稿人、审稿人提交保密意见、编辑决定、作者修回和再次送审。原稿、修回稿、各轮意见和决定分别保留；审稿人进入新一轮需要再次受邀和接受。测试账户、稿件、意见和 PDF 保存在本地。后台界面支持英语和简体中文；原静态演示页面仍保留 12 种语言选择。

## 本地运行

安装 Python 3.10 至 3.14 后，在项目根目录依次运行：

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r backend/requirements.txt
cd backend
python manage.py migrate
python manage.py seed_demo
python manage.py runserver 127.0.0.1:8000
```

Windows 如果提示找不到 `python3`，请改用 `python`；激活环境时使用 `.venv\Scripts\activate`。浏览器打开 <http://127.0.0.1:8000/>。`seed_demo` 会创建两个虚构测试期刊和作者、编辑、审稿人等测试账户，随机密码只在终端显示一次，请妥善保存。可使用不同浏览器会话分别登录各角色。重复执行会创建另一组测试数据，不会重置原账户。

创建管理员可运行 `python manage.py createsuperuser`，再访问 `/admin/` 管理测试期刊和角色。管理员不会仅因该身份获得工作台中的稿件访问权。

从上一版本地后台升级时，数据库迁移会为现有测试稿件建立初始版本和审稿轮次，并保留文件路径与审稿分配。该迁移不可直接回滚，升级前应备份测试数据库和文件；如需返回旧版，请恢复备份。

## 当前限制

后台尚未实现双盲匿名、完整的利益冲突声明、可配置编辑规则、发表、邮件、DOI、AI、病毒扫描、备份恢复、多因素认证及生产环境安全配置。目前只有 PDF 和作者回复支持版本记录，标题、摘要及其他附件还没有版本管理。审稿人在接受邀请前可看到标题和摘要；系统不保证文件或摘要已匿名。作者在账户及期刊有效时仍可查看自己的投稿；审稿人须保有有效的本刊审稿角色。

编辑可以填写会展示给作者的决定说明。系统不会自动向作者公开审稿人身份或保密意见，但编辑仍需核对说明内容，避免手动带入保密信息。录用和修回决定需要至少一份已提交的审稿意见，初筛拒稿可以不送审。

请只使用虚构数据。用于真实稿件之前，还须完成安全设计、文件隔离与扫描、加密、正式数据库、权限和并发测试、备份恢复及业务验收。完整说明见 [英文文档](README.md)。
