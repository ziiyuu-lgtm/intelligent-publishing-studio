# 多刊投稿审稿后台：本地测试说明

这是独立于原有静态演示页面的开发版后台，仅供虚构数据测试。它尚未连接 SCIENTARA 网站，不能用于真实稿件，也不能开放到公网。

目前可测试：机构与多刊、期刊角色、作者创建并提交稿件、编辑邀请本刊审稿人、审稿人接受或拒绝及提交保密意见。测试账户、稿件、意见和 PDF 保存在本地。后台界面支持英语和简体中文；原静态演示页面仍保留 12 种语言选择。

## 本地运行

安装 Python 3.10 至 3.14 后，在项目根目录依次运行：

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r backend/requirements.txt
cd backend
python manage.py migrate
python manage.py seed_demo
python manage.py runserver 127.0.0.1:8000
```

Windows 激活环境时使用 `.venv\Scripts\activate`。浏览器打开 <http://127.0.0.1:8000/>。`seed_demo` 会创建两个虚构测试期刊和作者、编辑、审稿人等测试账户，随机密码只在终端显示一次，请妥善保存。可使用不同浏览器会话分别登录各角色。重复执行会创建另一组测试数据，不会重置原账户。

创建管理员可运行 `python manage.py createsuperuser`，再访问 `/admin/` 管理测试期刊和角色。管理员不会仅因该身份获得工作台中的稿件访问权。

## 当前限制

后台尚未实现双盲匿名、利益冲突声明、多轮修回、编辑决定、发表、邮件、DOI、AI、病毒扫描、备份恢复、多因素认证及生产环境安全配置。审稿人在接受邀请前可看到标题和摘要；系统不保证文件或摘要已匿名。作者在账户及期刊有效时仍可查看自己的投稿；审稿人须保有有效的本刊审稿角色。

请只使用虚构数据。用于真实稿件之前，还须完成安全设计、文件隔离与扫描、加密、正式数据库、权限和并发测试、备份恢复及业务验收。完整说明见 [英文文档](README.md)。
