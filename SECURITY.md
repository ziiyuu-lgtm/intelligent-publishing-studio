# Security

This repository is a static prototype. It is not suitable for real manuscripts or personal information and must not be treated as a production publishing system.

Do not post suspected vulnerabilities, credentials, or confidential information in a public issue. If private vulnerability reporting is enabled in the repository's Security tab, use that channel. Otherwise, contact a maintainer through an established, verified private channel before sharing technical details. A dedicated security contact and response process still need to be established.

Future production systems require review of access control, tenant isolation, uploads, dependencies, secrets, logs, AI-provider data handling, backups, supply-chain security, and incident response.
